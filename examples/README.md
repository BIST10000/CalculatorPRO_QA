# Примеры

Актуальные входные данные для формы с семью строками функций и ожидаемые результаты находятся в **compatible/**. Эти JSON-файлы можно открыть кнопкой «Открыть JSON».

Файлы 01-zero, 02-linear, 03-boundary, 04-demo в корне этой папки относятся к прежней расширенной форме и внутренним тестам ядра. Они сохранены как история проверки, но не подходят для текущей формы. Их старые ожидаемые значения нельзя использовать для сравнения нового набора входных данных.
